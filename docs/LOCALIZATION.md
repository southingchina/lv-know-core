# Documentation language policy

Updated: 2026-10-24. Project: lv-know-core.

The default GitHub README is English. The full original Simplified Chinese reference is preserved in README.zh-CN.md. Japanese, Korean, Spanish, French, German and Brazilian Portuguese guides provide localized overviews, configuration entry points, usage examples, publication boundaries and license links. Guides may be shorter than the detailed Chinese reference.

This is documentation localization, not a claim that the application interface, CLI output, binary installer, Skill runtime or every linked technical reference supports these languages. No executable release was rebuilt for this update.

## Keeping versions consistent

When the README changes, check every language guide against the actual code and the detailed Chinese reference. Preserve executable commands, argument names, paths, configuration keys, exact trigger phrases and API identifiers. Never translate these into new interfaces that do not exist. Update capability boundaries, external dependencies, verification dates and limitations in all guides. Preserve LICENSE, NOTICE and third-party attribution verbatim. Flag an outdated translation instead of claiming it is current. Do not automatically invoke external translation services or send private material to them.
