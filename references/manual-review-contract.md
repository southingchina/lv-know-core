# 人工审核 Excel 契约

## 导出

只导出 `待人工判断` 候选。固定列为：编号、`candidate_id`、`candidate_hash`、来源卡 ID、易读表述、待判断原因、入库标记、人工修改、备注。

审核表冻结标题行，长文本自动换行；标记列使用醒目底色。技术 ID 可见是为了人工复核和稳定回流，不能只保存行号。

## 读取

- `1`：人工批准。
- 空白：继续待人工判断。
- 其他标记：拒绝应用并报告。
- 有人工修改且已批准：修改后的文字优先，原表达保存在 `source_claim`。
- 人工修改不能绕过后续语义合并。

读取时校验 candidate ID 唯一、候选存在、candidate hash 未变化。任何重复、未知或旧哈希都停止本次应用，不部分写入。

同一工作簿重复运行必须幂等：已应用的批准项成为 `no_op`，不能再次新增来源或知识点。空白项继续保留待判断。

`manual-approval-delta.json` 记录工作簿哈希、批准、人工修改、继续待判断和零变化 ID，不记录无关单元格，也不记录凭据。
